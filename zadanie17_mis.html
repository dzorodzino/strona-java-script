2. Czym jest funkcja w JS? Omów przy użyciu 4 podpunktów.

Odpowiedź:

  1. Funkcja to zbiór instrukcji, które można uruchomić poprzez podanie jej nazwy.
  2. Po wywołaniu funkcja wykonuje zapisany w niej kod.
  3. Funkcja może przyjmować argumenty, które są przetwarzane wewnątrz niej.
  4. Funkcja może zwracać wynik za pomocą słowa kluczowego return.

3. Omów metody getElementsByName, getElementById, getElementsByTagName.

Odpowiedź:

Metoda Opis
getElementsByName() Pobiera elementy o określonej wartości atrybutu name.
getElementById() Pobiera element o określonym identyfikatorze id.
getElementsByTagName() Pobiera elementy o określonym znaczniku, np. P lub DIV.

4. Omów właściwości innerHTML, innerText, className.

Odpowiedź:

innerHTML – umożliwia odczytywanie i zmienianie kodu HTML wewnątrz elementu.

innerText – umożliwia wstawianie lub odczytywanie zwykłego tekstu w elemencie.

className – umożliwia przypisanie lub odczytanie klasy CSS elementu.
