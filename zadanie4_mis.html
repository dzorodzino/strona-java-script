1) Kiedy powstał JavaScript (podaj datę).

JavaScript powstał w 1995 roku. Pierwsza wersja została stworzona przez Brendana Eicha w firmie Netscape.

2) Dlaczego jest to język skryptowy?

Ponieważ kod JavaScript jest wykonywany przez interpreter, bez konieczności wcześniejszego kompilowania całego programu.

3) Gdzie jest wykonywany JS (klient lub serwer)?

JavaScript może być wykonywany po stronie klienta, czyli w przeglądarce internetowej, oraz po stronie serwera, np. za pomocą Node.js.

4) Dlaczego JS to bezpieczne narzędzie?

JavaScript działa w środowisku przeglądarki, które ogranicza jego dostęp do systemu użytkownika. Dzięki temu skrypt nie może bezpośrednio wykonywać niebezpiecznych operacji, np. swobodnie odczytywać plików na komputerze.

5) Czy jest to język obiektowy, jeśli tak to dlaczego?

Tak. JavaScript jest językiem obiektowym, ponieważ pozwala tworzyć i używać obiektów, które posiadają właściwości i metody.

6) Wymień zalety JS:

Zaleta 1: Jest szybki i działa bezpośrednio w przeglądarce.

Zaleta 2: Umożliwia tworzenie interaktywnych stron internetowych.

Zaleta 3: Jest stosunkowo prosty do nauki i szeroko stosowany.

7) Framework to:

Framework to gotowy szkielet programu zawierający narzędzia, biblioteki i zasady, które ułatwiają tworzenie aplikacji.

8) Do aplikacji mobilnych można użyć Framework:

Do tworzenia aplikacji mobilnych można użyć frameworków takich jak React Native lub Ionic.

9) Aplikacje responsywne to:

Aplikacje responsywne to aplikacje, których wygląd i układ automatycznie dostosowują się do rozmiaru ekranu i rodzaju urządzenia.

10) Przepisz linię kodu i wyjaśnij, jak działa:

‹input type="button" name="przycisk" value="Nowa Strona" onclick="WinOpen(' ')"›

Wyjaśnienie: Kod tworzy przycisk o nazwie „Nowa Strona”. Po jego kliknięciu zostaje wywołana funkcja JavaScript WinOpen().

11) Przepisz linię kodu i wyjaśnij, jak działa:

window.open("obraz.html","okienko","toolbar=no,directories=no,menubar=no,height=280,width=160,top=200,left=200");

Wyjaśnienie: Instrukcja window.open() otwiera stronę obraz.html w nowym oknie o nazwie „okienko” oraz ustala jego wygląd, rozmiar i położenie.

toolbar=no → ukrywa pasek narzędzi.

directories=no → ukrywa pasek katalogów.

menubar=no → ukrywa pasek menu.

height=280 → ustala wysokość okna na 280 pikseli.

width=160 → ustala szerokość okna na 160 pikseli.

top=200 → ustala odległość górnej krawędzi okna od góry ekranu na 200 pikseli.

left=200 → ustala odległość lewej krawędzi okna od lewej strony ekranu na 200 pikseli.

12) Opisz następującą instrukcję window.close()

Instrukcja window.close() zamyka aktualnie otwarte okno przeglądarki. Najczęściej jest używana po kliknięciu przycisku „Zamknij okno”.

13) Jak wyświetlić instrukcję, która nie powinna się wykonywać, a tylko wyświetlać?

Można użyć encji HTML, np. ‹ zamiast znaku < oraz › zamiast znaku >. Można również umieścić kod w elemencie ‹pre›, który pozwala wyświetlać tekst z zachowaniem jego formatowania.
