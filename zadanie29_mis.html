1. W jaki sposób można określić właściwość danego obiektu? (Dwa sposoby wraz z przykładami).

Odpowiedź:

Właściwość danego obiektu można określić, czyli przypisać wartość do pola odpowiedzialnego za daną właściwość, na dwa sposoby.

Sposób 1 – za pomocą kropki:
Zapis:
nazwa_obiektu.nazwa_właściwości = wartość;

Przykłady:
auto.marka = "Opel Omega";
auto.rok = 1996;
auto.cena = 25000;

Sposób 2 – za pomocą nawiasów kwadratowych:
Zapis:
nazwa_obiektu["nazwa_właściwości"] = wartość;

Przykład:
auto["cena"] = 25000;

2. W jaki sposób można odwołać się do pól (właściwości) i metod?

Odpowiedź:

Do właściwości i metod obiektu można odwołać się podobnie jak do zwykłych zmiennych i funkcji. Przed nazwą właściwości lub metody należy umieścić nazwę obiektu oraz kropkę.

Przykład:
console.log(samochod1.kolor);
samochod1.pokaz();

1. samochod1.kolor – odwołanie do właściwości obiektu.
2. samochod1.pokaz() – wywołanie metody obiektu.

3. Wymień cechy charakterystyczne konstruktora.

Odpowiedź:

1. Jest wywoływany automatycznie podczas tworzenia nowego obiektu.
2. W tradycyjnym modelu klasowym jego nazwa jest taka sama jak nazwa klasy.
3. Nie zwraca jawnie żadnej wartości.
4. Może przyjmować argumenty, podobnie jak zwykła funkcja lub metoda.
5. Służy do inicjalizacji właściwości nowo tworzonego obiektu.
6. Do tworzenia obiektu za pomocą konstruktora używa się słowa kluczowego new.

4. Konstruowanie obiektu na podstawie przykładu – obiekt ma trzy pola oraz jedną metodę.

Odpowiedź:

Obiekt można utworzyć za pomocą nawiasów klamrowych. Wewnątrz zapisujemy jego właściwości oraz metody.

Przykład:

var osoba_1 = {
nazwisko: "Kowalski",
imie: "Jan",
zawod: "piekarz",
wyswietl: function() {
document.write(this.nazwisko + " " + this.imie);
}
};

osoba_1.wyswietl();

Obiekt osoba_1 posiada:
1. Trzy pola: nazwisko, imie, zawod.
2. Jedną metodę: wyswietl().

Metoda wyświetla nazwisko oraz imię osoby.

5. Znaczenie słowa this. Jak oddzielamy pola oraz metody?

Odpowiedź:

Słowo kluczowe this pozwala odwołać się do pola lub metody obiektu z wnętrza tego obiektu.

Przykład:

var osoba = {
imie: "Jan",

wyswietl: function() {
alert(this.imie);
}
};


W powyższym przykładzie this.imie oznacza właściwość imie aktualnego obiektu.

Pola i metody w obrębie jednego obiektu oddzielamy przecinkami.

6. Konstruktor w JS na podstawie przykładu wraz z opisem.

Odpowiedź:

W JavaScript konstruktor można utworzyć za pomocą zwykłej funkcji. Służy ona do tworzenia obiektów posiadających określone właściwości i metody.

Przykład:

function klient(nazwisko_k, imie_k, zawod_k) {
this.nazwisko = nazwisko_k;
this.imie = imie_k;
this.zawod = zawod_k;

this.wypisz = function() {
alert(this.nazwisko + " " + this.imie);
};
}


Opis przykładu:
1. function klient() – definiuje konstruktor o nazwie klient.
2. nazwisko_k, imie_k, zawod_k – parametry konstruktora.
3. this.nazwisko, this.imie, this.zawod – właściwości tworzonego obiektu.
4. this.wypisz – metoda obiektu wyświetlająca nazwisko i imię.
5. this – odnosi się do aktualnie tworzonego obiektu.

Konstruktor umożliwia tworzenie wielu obiektów o takiej samej strukturze, ale z różnymi wartościami właściwości.

7. Znaczenie słowa kluczowego new wraz z przykładem.

Odpowiedź:

Słowo kluczowe new służy do tworzenia nowego obiektu na podstawie konstruktora.

Przykład:

var osoba1 = new klient("Kowalski", "Jan", "kierowca");

var osoba2 = new klient("Nowak", "Anna", "sekretarka");

Opis:
1. new klient() – tworzy nowy obiekt na podstawie konstruktora klient.
2. osoba1 – pierwszy utworzony obiekt.
3. osoba2 – drugi utworzony obiekt.

Powstały dwa niezależne obiekty posiadające te same właściwości i metody, ale różne wartości danych.

8. Znaczenie słowa kluczowego prototype wraz z przykładem i opisem.

Odpowiedź:

Właściwość prototype służy do dodawania właściwości i metod do konstruktora. Dzięki niej wszystkie obiekty utworzone na podstawie tego konstruktora mogą korzystać z dodanych elementów.

Przykład:

function klient() {
this.nazwisko = "Bielski";
this.imie = "Paweł";
}

klient.prototype.pisz_dane = function() {
document.write(this.nazwisko + " " + this.imie);
};

klient.prototype.zawod = "kierowca";

var osoba1 = new klient();

osoba1.pisz_dane();


Opis przykładu:
1. function klient() – tworzy konstruktor.
2. this.nazwisko i this.imie – określają właściwości obiektu.
3. klient.prototype.pisz_dane – dodaje metodę pisz_dane() do prototypu konstruktora.
4. klient.prototype.zawod – dodaje właściwość zawod do prototypu.
5. new klient() – tworzy nowy obiekt.
6. osoba1.pisz_dane() – wywołuje dodaną metodę.

Właściwość prototype pozwala dodawać metody i właściwości do konstruktora, dzięki czemu wszystkie obiekty utworzone na jego podstawie mogą z nich korzystać.

Nowo utworzone obiekty automatycznie uzyskują dostęp do właściwości i metod zapisanych w prototypie.
